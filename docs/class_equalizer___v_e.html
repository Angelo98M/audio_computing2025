Detailed Description

Ein parametrischer Equalizer mit mehreren Bändern (LowPass, LowShelf, Peak, HighShelf, HighPass).

Diese Klasse implementiert einen Mehrband-EQ mit fünf Filtertypen pro Kanal, basierend auf JUCEs DSP-Modulen. Die Filter können dynamisch aktualisiert und in einem Audioblock verarbeitet werden.
