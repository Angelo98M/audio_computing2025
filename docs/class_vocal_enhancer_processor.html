Detailed Description

AudioProcessor-Klasse zur Sprachbearbeitung mit Equalizer, De-Esser, Exciter und Kompressor.

Diese Klasse verwaltet eine vollständige DSP-Kette zur Verbesserung von Sprachsignalen, unterstützt Standalone-Wiedergabe, Parameterverwaltung, Dateiladen und Preset-Funktionen.
