Detailed Description

Eine einfache De-Esser-Klasse zur Reduzierung von Zischlauten (Sibilanz) in Audiosignalen.

Diese Klasse filtert einen spezifischen Hochfrequenzbereich (typischerweise Sibilanzbereich) heraus und verarbeitet diesen separat mit einem Kompressor. Sie basiert auf JUCEs DSP-Modulen.
