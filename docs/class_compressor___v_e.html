Detailed Description

Eine einfache Hüllkurven-basiere Kompressor-Klasse, basierend auf JUCEs DSP-Modulen.

Diese Klasse kapselt einen JUCE-Kompressor und bietet Funktionen zum Konfigurieren und Bearbeiten eines Audiobuffers mit typischen Parametern wie Threshold, Ratio, Attack und Release.
