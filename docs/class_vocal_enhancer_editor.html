Detailed Description

Die grafische Benutzeroberfläche (GUI) für das VocalEnhancer-Plugin.

Diese Klasse definiert alle Steuerelemente, Anzeigen und Verbindungen zum AudioProcessor. Sie umfasst Komponenten für Kompressor, De-Esser, Equalizer, Exciter, ADSR, LevelMeter und Dateiverwaltung.
