Detailed Description

Eine einfache visuelle Pegelanzeige für Audiosignale.

Diese Komponente zeigt einen vertikalen Pegelbalken an, der auf einem externen, atomar bereitgestellten Float-Wert basiert. Der Wert wird regelmäßig aktualisiert und grafisch als dB-skaliertes Level dargestellt.

Typische Verwendung: RMS-/Peak-Anzeige in einem Audio-Plugin.
